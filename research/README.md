# Research

This directory contains durable research methods, hypotheses, experiment indexes, and evidence used to improve the system.

## Core loop

`Question → Hypothesis → Method → Experiment → Evaluation → Decision → Registry`

## Rules

1. Prefer explicit, testable methods over opaque prompt fragments.
2. Separate discovery evidence from validation evidence.
3. Mark in-sample and out-of-sample results explicitly.
4. Preserve data source, timestamp, and provenance for important findings.
5. Do not promote a method because it is fashionable; require measurable improvement on the target workload.
6. Retire methods when they become stale, unreliable, duplicated, fragile, or consistently inferior.

## Key artifact

`method-registry.md` is the durable index of methods and their lifecycle status.
